# 本地内容管理

本地管理页无需第三方账号或付费服务。启动公开站点开发服务器后，在导航栏点击“管理内容”，或打开 `http://localhost:4321/admin/`。

## 可编辑内容

- 网站标题、简介和首页背景轮播；可添加图片并设置缩放、位置和轮播间隔。
- About、Contact、作品分类和作品顺序。
- 作品标题、日期、类型、简介、主图、图库、详情模板及可排序的正文、图片、图文、引用和链接区块。
- 图片上传到 `public/images/` 下按用途及作品分类组织的目录。

点击顶栏“保存”后，文字和结构写入 `src/data/content/` 中相应的 JSON 文件，图片写入 `public/images/`。管理页使用可直接编辑的画布，右侧为组件和设置工具；公开页面会在刷新后读取已保存内容。发布前运行 `npm run build` 并按现有静态网站流程发布。

管理页和文件写入 API 只会通过本机开发服务器提供，不会进入静态构建产物。原 Sanity 集成已从代码和依赖中移除；此前的云端 Sanity 项目没有被本地文件操作触及，当前网站不会读取它。`.env` 及 `studio/.env` 是被忽略的本机文件，新流程不读取它们。
