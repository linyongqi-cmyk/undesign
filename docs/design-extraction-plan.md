# 林永祺作品集可复用样式与组件盘点

范围为前台、作品画布和本地管理控件。现状见 [DESIGN.md](../DESIGN.md)。本轮只盘点和列方案，表内变量名与组件名为后续实施建议。

## 颜色和间距

| 项目 | 重复位置与现状 | 拟议处理 |
| --- | --- | --- |
| 管理面板近白背景 `#fbfbfa` | 顶栏、导航栏、设置弹层和裁切窗口。管理 CSS 中同色字面量有 31 处，包含其他用途 | 按语义迁移控件外壳，建议增加 `--admin-ui-panel`；画布底色保留作品样式来源 |
| 控件白底、灰色标签与细边框 | 普通字段、画布字段、文字样式与裁切设置。已有 `--admin-ui-surface`、`--admin-ui-muted`、`--admin-ui-border` | 优先改为引用现有变量。只迁移当前计算值与语义都相同的选择器；`#dededb`、`#ddd`、`#d8d8d5` 逐处核对 |
| 管理确认按钮深底 `#202020` | 顶栏保存、文字样式确认、深色通用按钮 | 对同值确认按钮使用管理端动作变量，保留各处既有悬停、禁用表现 |
| 前台背景、主文字和细分隔线 | 根样式、正文导航和当前分类沿用近白与近黑；Research 分隔线和 Contact 列表使用现有 `--line` | 保留并优先复用 `--line`。近白背景与主文字可分别引用现有根规则中的值；作品文字颜色继续读取 `site.json` |
| 作品独立区块 `12px` | 图文分栏正文、文章正文/图库及摄影介绍处有字面量，媒体部分已有 `--split-media-gap` | 建议共享 `--work-block-gap`，只替换同义的独立区块间隔。现有媒体间距变量、群组内 0 与媒体说明的可设间距照原规则 |
| 管理间距 `4 / 8 / 12px` | 文字样式的标签间隔、字段间隔和面板内边距；裁切比例与确认行也有 4/8px 字面量 | 先在设置面板复用标签间隔、表单间隔与普通弹层内边距。栅格 16px、分栏 48px 及作品间距仍由前台和画布排版决定 |

盘点入口为 `src/styles/global.css`、`scripts/local-admin/styles.css`、`src/data/content/site.json`。字面量出现次数只用于定位，实施时以选择器的用途和实际计算样式为准。

## 组件

| 候选 | 重复入口与现有共享点 | 拟议处理 |
| --- | --- | --- |
| 管理操作图标按钮 | 顶栏撤回/重做/保存、画布工具栏设置/删除、右栏样式按钮。React 已有 `AdminActionIcon`、`ContentTypeIcon`、`CanvasActionRail` | 先统一使用现有按钮样式及 SVG 尺寸入口。普通图标、带文字按钮、展开和切换状态按用途保留；布局示意图与下拉箭头保留专用尺寸 |
| 管理表单字段 | 网站设置原生表单、作品基本字段、文字样式字段、裁切比例 | 先收敛标签、控件外观和聚焦样式，复用现有 `--admin-ui-*`。HTML 与 React 保留原入口，必要时在 React 内共享同结构的字段。数值单位、多行、范围、下拉和文件输入保留原语义 |
| 画布设置弹层 | 图片大小、文字说明、图片链接、整体缩进与组内排序已有 `CanvasPopoverAction` | 先复用弹层外壳、字段间距与确认区样式。保留已存在的定位、关闭、应用、焦点恢复和拖拽事件。裁切窗口继续独立 |
| 媒体说明呈现 | 普通图片、轮播、免责声明、本地视频和在线视频已有共享说明逻辑；前台 `MediaCaption.astro`，画布 `MediaCaptionAction`，两端共享样式与对齐函数 | 优先在已有 `media-caption-style.js`、`media-caption-layout.js` 复用规则，保留 Astro 展示和 React 编辑入口。确认上下说明及同排媒体对齐后再判断是否还有重复标记可提取 |
| 作品缩略图网格 | Product 方形网格，Visual 与 Photography 瀑布流，管理分类画布也显示封面 | 优先核对共用裁切、灰阶和标题状态。前台链接和画布选择/排序保持各自语义；方形网格和瀑布流继续使用各自的封面裁切数据 |

组件定位见 `src/components/admin/PuckWorkEditor.jsx`、`scripts/local-admin/index.html`、`scripts/local-admin/preview.js`、`src/components/content/MediaCaption.astro` 和 `src/pages/works/[category].astro`。

## 实施顺序与验收

1. 记录桌面与 390px 前台基线、同一作品的管理画布与前台，以及管理按钮和字段的默认、悬停、聚焦、选中和禁用状态。
2. 先在现有样式表内以同值替换管理控件颜色和间距。逐批对照实际计算值、边缘与间距，再落到图标、字段和弹层。遇到确有视觉差异的近似色或状态，保留现状，另列需决定的调整。
3. 再处理前台与画布共享的作品间距和缩略图/说明规则。对照《樓》的图文分栏，加查摄影图集、Research Log、连续群组和上置媒体说明。确认保存过的作品内容、顺序、字号、比例和说明位置一致。
4. 运行 `npm run build`，复核鼠标、键盘及窄屏。迁移后仍须保留图标辅助名称、焦点返回、撤回和保存行为。每批都能单独回退。

本轮观察了本地桌面首页和《樓》前台、桌面《樓》管理画布，以及 390px 下重新载入的《樓》前台。作品首图和可见图文结构用于记录现状；全量计算样式、管理交互状态及不同模板的逐项对照留到实施基线。
