# 功能规格归档

> 本文档归档自原 `WORKFLOW.md` 与 `README.md` 的功能规格说明，按需查阅，具体实现以当前代码为准。

## 图片悬停放大

仅“图片”组件（含群组内图片）可在工具栏的“图片悬停效果”中开启。可设置左中、居中、右中基点，并输入 1.1–2.5 的放大倍率，或选择 1.25x、1.5x、1.75x、2.0x、2.5x 快捷值；管理画布使用播放图标预览，点击“应用”写入草稿，再保存到本机。按 Esc 或点击关闭预览。保存后在前台桌面鼠标悬停生效，无阴影，保持原裁切与排版；靠近视口边缘时自动避让并限制放大尺寸；高图仍保留至少 1.1 倍放大，超出视口的部分由视口裁切。放大后的图片优先占有整个放大区域，被它遮挡的相邻图片不触发；离开放大区域后，才检测相邻图片露出的区域并切换，移出保留缩回动画。手机宽度和触屏不启用，轮播、免责声明及视频不提供此设置。旧图片默认关闭。

## 媒体说明与图片链接文字

管理页右侧 Add Media 一栏的五个组件（图片、图片轮播、免责声明、本地视频、在线视频链接）共用同一套“文字说明”：说明显示在媒体视口外部，可选上方或下方，间距 0–120px（默认 4px，可直接选 4px、8px、12px），点“应用”写入草稿，为空时不渲染也不占位。工具栏里的“文字说明”按钮在五种媒体中打开同一表单；轮播使用整组一条说明，不随图片切换；群组本身不设整组说明，组内媒体各自设置。说明只保存文字、位置和间距，样式复用文字组件的“备注”全站预设（字体、字号、字重、颜色、行高等），保持透明背景，管理画布与前台共用同一份数据和样式。

同一横向行里只要有一项把说明放在上方，其余媒体会自动下移对齐媒体顶线，删除说明后复位。普通图片另有“图片链接文字”，显示在最终可见图片视口的右下角，只覆盖 HTTPS 站外链接，可新标签或当前标签打开；标签始终可见，裁切或悬停放大时仍固定在视口右下角并随画面等比放大，放大后仍可点击。图片其他区域不跳转，键盘聚焦到原链接，放大层中的副本不重复进入 Tab。图文分栏、布局群组、自由尺寸组、图文分栏和图集内的普通图片同样适用；轮播每张图与宽幅旧媒体不提供图片链接文字。旧内容里的 `caption` 字符串继续作为说明文字读取，说明位置与间距存在 `captionSettings`，图片链接文字存在 `linkLabel`。

## 撤回与保存

管理页用同一套历史记录覆盖画布及页面设置，顶栏按钮和 ⌘Z / Ctrl+Z 可撤回，⌘Shift+Z / Ctrl+Shift+Z（Windows 也可 Ctrl+Y）可重做。正文、小标题、参数和直接编辑的字段按每次有效输入单独记录，粘贴、中文/日文输入法的一次确认、一次拖拽或一次“应用”分别为一步；尚未应用的设置表单使用输入框本身的撤回，确认应用后加入页面历史。

所有页面共享当前标签页的历史，切换作品或保存不会清空；跨页撤回会返回相应页面。最多保留最近 2000 步，手动刷新或关闭标签页后历史清空。保存后撤回会重新标为未保存，需要再次保存才写入本机。全站文字样式和图片轮播间隔确认后也先进入草稿，随顶栏保存一起写入。自动清理会保留历史引用的图片和视频；素材保护持续到本地开发服务重启，避免另一管理标签页提前清理素材。

## 字符缩进与简洁工具栏

文字与五种媒体组件提供“整体缩进”：先设每字符宽度（1–200px），再设字符数（0–20），实际缩进为两者相乘。文字默认取对应文字组件当前字号，媒体默认14px；可以手动修改。旧内容未指定字符宽度时保留原有 ic 缩进效果。字段 blockIndent 与 blockIndentSize 随草稿保存并可撤回，媒体说明跟随媒体一起缩进，等高行保留媒体原比例。

简洁工具栏将设置、更换、删除统一为“图标＋两字”的外部按钮，群组另有排序快捷入口。按钮放在内容边界之外，按当前组件悬停或聚焦显示。群组面板标题为“群组设置”，不显示重复的群组标识。内部功能按布局、内容与链接、图片效果分组，并在同一面板内展开，一次展开一项；图片裁切仍使用独立预览窗口。管理页统一使用简洁工具栏，不再提供旧工具栏切换。交互调整前的代码备份保存在 backups/editor-controls-before-compact/。

免责声明的“出典：”与来源链接同行；图片角落链接文字复用全站“站外超链接”的字体预设。

## 管理 UI 控件规范

编辑界面使用共享 UI 字体、灰阶和细边框：标签 10px，控件 11px，侧栏标题 12px，独立弹窗标题 14px；常规输入控件高 32px、小圆角 2px，常规操作图标为 16px / 1.5px 线条。表单间距 8px、标签间距 4px，普通弹层内边距 12px。仅作用于编辑控件，不覆盖作品画布内容的字体与排版。群组设置按钮内缩 2px 添加 1px 内描边。裁切仅保留“图片裁切”、必要比例/范围字段及取消/应用，主按钮使用黑色。

本轮检查记录见 docs/admin-ui-audit.md。

## 管理页操作反馈

带“应用”的设置先校验，再写入草稿并折叠/关闭当前表单，在顶部栏显示“已应用”；顶栏保存才写入本机。即时编辑字段在选择变更或输入失焦后提示已更新草稿。关闭未应用表单丢弃临时值；即时编辑通过撤回恢复。异步确认提供处理中状态，失败保留编辑内容。检查记录见 docs/admin-interaction-audit.md。

普通单张图片的“显示模式”支持 Width（百分比）与 Height（80–1200px）；Height 根据原图或裁切比例等比显示。切回 Width 清除固定高度。显示高度存入区块 displayHeight，支持撤回与保存；图片轮播不使用此选项。应用成功提示仅显示“已应用”。

管理操作提示统一显示在顶部栏：成功仅显示“已载入”“已应用”“已保存”“已更新”“已调整”等短文字，无图标或第二行说明；错误保留必要原因。保存成功仅显示“已保存”。图标按钮清除默认内边距，以按钮边框盒的几何中心对齐 SVG；带文字的图标按钮按整组内容居中。Research 媒体说明不继承正文段落的额外底部外边距。

## 选择文字组件并作群组

所有作品详情页提供“选择文字组件”。仅可将同一内容区域内至少两个连续文字组件（正文、小标题、备注、参数、站内/站外链接、引用）组成内容群组；图片、轮播、视频及已有群组不可选，图文分栏左右不能跨区成组。群组沿用内部 0px、外部 12px 的规则，支持撤回、解散和保存后重新读取。链接的显示文字保留编辑时输入的换行，画布与前台一致。

2026-11-19 管理画布内的内容链接仅用于选择和编辑，普通点击、键盘激活和中键均不触发跳转；前台链接正常跳转。图文分栏右侧独立区块间距为 12px，内容群组内部仍为 0。右侧配套的媒体组件（含免责声明）以上/下边框对齐，纯文字继续按文字边界对齐。拖入接收区不延伸覆盖后续组件。

免责声明固定显示“この写真は著作権法上の関係により、出典のみ記載している。”，无手动换行，不提供声明正文编辑；来源文字、HTTPS 链接与媒体说明仍可编辑。群组内免责声明也提供“显示宽度”，按所在区域百分比调整，保存为 displayWidth，支持撤回，画布与前台共用。

## 分类列表展示方式

分类设置中的“列表展示方式”可选作品缩略图网格、瀑布流、研究日志列表。Product 初始保留方形网格，Visual 与 Photography 初始使用瀑布流；切换模式保留作品正文和封面设置。瀑布流按作品顺序向较短列补位，使用原图比例，可在作品编辑工具区的“封面比例”选择原图、3:2、1:1、4:5、2:3，或通过裁切设置其它比例。瀑布流裁切独立保存为 masonryThumbnail，方形网格继续使用 imageScale/imagePosition；两者不相互覆盖，也不影响详情页图片。替换封面会重置两套裁切。应用先进入草稿，顶栏保存写入本机，支持撤回与重做。
