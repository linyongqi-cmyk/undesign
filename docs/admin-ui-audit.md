# 管理页 UI 一致性检查（2026-11-18）

本轮统一编辑控件，保留作品画布复用的前台字体、图像和排版。

| 发现的差异 | 处理 |
| --- | --- |
| 裁切有英文 CROP PREVIEW 与重复预览标题 | 仅保留“图片裁切”，比例数值并入比例标签，缩短范围标签 |
| 裁切使用鲜绿色按钮、绿色圆角预览框、大按钮和背景模糊 | 改成黑色主按钮、灰色细边框、方形预览和纯色遮罩；底部取消/应用右对齐 |
| 文字样式表单使用 8–10px 大圆角和灰底，与普通表单不一致 | 复用 2px 小圆角、白底、1px 细边框、32px 控件高度 |
| 样式、轮播、拾色器、组件弹层分别设置字体和外框 | 共用管理 UI 字体、灰阶、边框、圆角和轻阴影；保留色板色彩 |
| “正文样式”等侧栏标题和回收站标题使用了不同的默认尺寸 | 标签 10px，控件 11px，侧栏标题 12px，独立弹窗标题 14px |
| 小图标混用 15/16px 和文字箭头 | 操作图标统一 16px、1.5px 圆端点线条；排序箭头复用共享 SVG |
| 各类控件与标题间距零散 | 表单主间距采用 8px，标签间距 4px，弹层内边距 12px，裁切侧栏 16px |
| 群组和单组件的设置按钮难区分 | 群组按钮在外框内缩 2px 增加一圈 1px 浅灰描边 |
| 弹窗焦点使用默认蓝色而表单焦点使用灰色 | 编辑表单使用一致的灰色键盘焦点轮廓 |

## 核对范围

已在浏览器打开：首页与网站设置、个人介绍、联系方式、作品分类与管理、回收站、新增作品、作品画布、全站文字样式、拾色器、轮播间隔、组件/群组设置和图片裁切。裁切进行了比例切换、应用、撤回，检查草稿已撤回，未保存作品内容。窄屏另核对裁切和文字设置布局。

代码检查覆盖 scripts/local-admin/ 的管理页面与样式，以及 src/components/admin/、裁切编辑器和共享图标。上传、实际删除、拖拽放置等依赖素材或内容变化的状态未逐一执行；对应控件通过共享样式与源码核对。

保留的功能性区别：作品画布字体与尺寸来自内容；色板需要彩色；错误/未保存提示、拖放与选中轮廓保留语义色；裁切操控点、滑杆圆点与字号不作为普通图标统一尺寸。

本轮之前的样式和裁切代码保存在 backups/admin-ui-before-unification/。
