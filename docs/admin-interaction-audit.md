# 管理页交互检查（2026-11-18）

## 统一规则

- 有“应用”的表单：校验通过后写入草稿，关闭或折叠当前表单，并显示具体功能已应用；仍需顶栏保存到本机。
- 即时编辑：有效输入直接进入草稿，选择项变更或输入框失焦时显示已更新草稿；不逐字弹提示。
- 保存、样式确认、轮播确认和裁切确认：提供处理中状态，阻止重复提交；失败保留修改并显示错误。
- 取消或关闭未应用表单：丢弃表单临时值；重新展开读取当前草稿。即时编辑的字段需用撤回恢复。
- 撤回/重做：显示已执行及当前是否与本机保存一致。

## 按控制组件检查的代码路径

| 范围 | 检查内容与处理 |
| --- | --- |
| 图片、轮播、免责声明、本地视频、在线视频 | 共用 CanvasPopoverAction 的应用回调反馈、折叠、表单校验；即时选项标注修改进入草稿 |
| 图片悬停 | 原来应用后停留且无反馈；改为应用后折叠，保留草稿值 |
| 宽度、等高/等宽、整体缩进、说明、链接、来源 | 校验后的关闭回调统一提示；无效表单不执行成功回调 |
| 群组布局、侧边间距、排序 | 数值草稿状态移到表单内部，取消后不残留；补齐无快捷值时缺少应用入口；排序提示 |
| 全站文字样式 | 应用前校验输入；无效数字不再失焦静默恢复；处理中/失败/成功状态；取消与 Escape |
| 全站轮播间隔 | “保存”更名“应用”；处理中状态；明确取消入口；成功关闭并提示 |
| 图片裁切 | 应用中按钮文字与禁用；完成关闭并提示；异常保留编辑窗口 |
| 首页、个人介绍、联系方式、作品元数据 | 直接编辑字段的变更反馈；复选框和选择项立即反馈 |
| 创建、分类移动、排序、上传、回收站 | 创建校验提示，成功/失败提示；既有处理状态保留 |
| 顶栏保存与历史 | 保存处理中、失败、成功反馈；应用草稿与写入本机区分；撤回/重做结果反馈 |
| 浏览与预览 | 切换页面、折叠、预览不标作内容应用；保持原有选中、展开、预览状态 |
