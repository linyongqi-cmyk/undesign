# 摄影图集点击放大与摄影说明：设计说明及实施步骤

日期：2026-11-21。状态：点击放大、逐图说明与前后台共享查看器已实施。每次新开查看器时说明默认收起；在当前查看会话中展开/收起一次后，后续照片继承当前状态。图片左下方箭头向下，展开后转向右；文字位于箭头右侧并顶端对齐。横图说明行宽为图片一半，纵图说明行比图片窄 24px；文字字号为原来的 12px，其余样式沿用“正文段落”预设。说明展开不改变图片坐标或尺寸。前台桌面/窄屏及管理画布已本地核对；含图片链接文字的图库条目未验证，未发布。

## 一、目标与边界

为 Astro 静态作品集的“摄影图集”模板增加可选的图片点击放大，以及每张图片独立的“摄影说明”。保留现有极简视觉、图集布局与响应式行为，只改本功能需要的代码，不重构无关模块，不推送 GitHub、不发布。

实施前阅读根目录 AGENTS.md、README.md、WORKFLOW.md、交接.md、修改记录.md，以及交接与修改记录写作指南.md（若缺失，按 AGENTS.md 的结构维护）。检查工作区已有改动，不能覆盖其他任务成果。

实际内容源是 `src/data/content/`；旧路径 `src/data/portfolio.ts` 已不存在。图片放在 `public/images/`，构建输出不能作为内容源。

## 二、已明确的需求

### 作品级开关

- 管理页选择“摄影图集”模板后提供“点击图片放大”开关，每个作品独立设置。
- 旧作品默认关闭，不改变原有行为。
- 开启后作用于作品的摄影图集，不自动扩展至上部正文图片、轮播或其他媒体。

### 前台放大

- 从用户点击的那张图片开始。
- 图片位于屏幕中心，保持比例，以高度 70vh 为基准。
- 后方页面覆盖白色半透明模糊背景，图片与说明清晰。
- 有说明的图片在左下方、图片外侧显示向下箭头按钮；说明默认收起，点击后箭头转向右，文字在按钮右侧展开并与按钮顶部对齐。按钮与文字组成的说明行宽度不超过图片对应的说明宽度。
- 展开或收起说明时，图片保持原位置和尺寸。
- 横图说明行宽度为图片宽度的一半；竖图和正方形说明行比图片窄 24px，在右侧留出约一个箭头按钮宽度。左侧按钮占据说明行内空间，文字填满剩余宽度；文字左对齐，不添加文本框底色。
- 关闭按钮只显示“×”，不绘制圆形边框或底形。
- 点击放大的图片切换下一张，最后一张之后循环到第一张。说明展开状态在当前查看会话内沿用到后续照片；关闭后重新打开则从收起状态开始。
- 用户已明确：切换按实际视觉顺序，从左到右、从上到下，不能直接按后台数组或 DOM 列顺序。

### 摄影说明

- 每张摄影图集图片增加独立的“摄影说明”。
- 编辑入口位于图片控制面板内，区别于现有“文字说明”“图片链接文字”。
- 只有作品开启点击放大时才显示入口。
- 有非空说明时，图片左下方显示向下箭头；每次进入查看器时说明默认收起。
- 点击箭头后，箭头转向右，文字在箭头右侧展开并与箭头顶部对齐；再次点击收起。展开/收起状态在本次查看会话内保持，后续照片继承当前状态。横图说明行（按钮与文字整体）宽度为图片的一半，竖图（含正方形）说明行宽度为图片宽度减 24px。
- 展开/收起不得移动或改变图片尺寸。
- 文本左对齐、透明底，沿用“正文段落”全站文字样式预设；说明随当前图片切换。

## 三、未确认细节与实施默认值

## 四、实际视觉顺序

### 当前结构

`src/lib/content/photography-gallery-layout.js` 中的 `distributePhotographyGallery()` 按图片比例，将图片依次分配给较短列。因此后台数组顺序、DOM 先左列后右列的顺序、屏幕视觉顺序可能不同。

### 排列定义

瀑布流没有严格统一的横向行。本设计将“从左到右、从上到下”具体化为：

1. 以图片实际可见视口顶部的位置判断先后。
2. 顶部处于同一视觉行的图片从左到右。
3. 再进入下一视觉行。
4. 图片说明、编辑工具栏和外边距不作为测量边界。

```text
左图 A 顶部 0       右图 B 顶部 0
左图 C 顶部 320     右图 D 顶部 510

顺序：A → B → C → D → A
```

不能为了凑左右一对而忽略实际顶部位置。上述瀑布流行定义是对用户方向要求的技术细化，并非用户另行确认的精确算法。

### 算法建议

- 收集当前作品可放大图片视口的条目标识、top、left。
- 先按 top 精确排序，再按 left 排序。
- 依次建立视觉行：每行以第一项顶部为固定基准，允许约 2 CSS px 误差。
- 行内按 left 排列，拼接各行生成序列。
- 不在比较函数中直接做两两“差值小于 2px 则同一行”的判断，避免比较关系不传递。

### 生命周期

- 打开前计算当前布局的视觉序列，并从被点击条目开始。
- 通过条目标识定位当前项，不能只用 src：同一个文件可能重复出现。
- 窗口尺寸变化、手机旋转造成布局变化时重新计算，继续保持当前条目。
- 关闭后丢弃序列，下次打开重新计算。
- 移动端单列按最终屏幕位置由上到下，不沿用桌面序列。
- 不为排序强制下载所有大图；为图片提供正确的固有尺寸或比例占位，避免懒加载导致高度不稳定。

## 五、数据设计

建议字段名可按项目规范调整，但语义必须独立：

```ts
type Work = {
  photographyLightboxEnabled?: boolean;
};

type ContentImage = {
  photographyDescription?: string;
};
```

```json
{
  "template": "photographyGallery",
  "photographyLightboxEnabled": true,
  "gallery": [
    {
      "src": "images/works/photography/example.jpg",
      "alt": "作品图片",
      "photographyDescription": "Tokyo, 2026\n摄影说明"
    }
  ]
}
```

- 缺失开关等同关闭，缺失说明等同空文字。
- 兼容旧字符串图片，不批量改写旧作品默认字段。
- 不借用 caption、captionSettings、linkLabel 或 alt。
- 说明随图集条目一起排序、删除、撤回；重复文件的说明仍独立。
- 本次渲染可使用唯一条目标识，不要求仅为本功能给全部旧图新增持久 ID；禁止只用 src 作唯一标识。

## 六、管理端设计

### 总开关

在模板选择和 Photography 分类行下方显示“点击图片放大”。仅当前模板为 photographyGallery 时显示。改变后进入草稿，支持撤回、重做，顶栏保存后写入本机。摄影作品上部宽度字段标签显示为“UP/vw”。

### 说明表单

- 图集中每张图片设置面板增加“摄影说明”。
- 总开关开启才显示入口，与原有两个说明/链接入口分离。
- 多行输入，点击“应用”一次写入草稿，沿用“已应用”反馈。
- 未应用关闭时丢弃临时值；空白内容前台不渲染。
- 不将说明显示到普通图集下方。

### 更新路径

`PhotographyGalleryCanvas` 管理作品根级 gallery，通过图片组件的 onImageChange 回调更新条目。新增说明必须沿用该路径，不能套普通正文图片的区块查找与保存方式。

通过明确参数或 extraActions 扩展共享图片编辑器，不能让其他模板出现摄影专属字段。

### 画布预览

- 画布普通点击继续用于选择和编辑，不直接打开前台查看层，以免影响拖动。
- 提供独立“预览放大”入口，从当前图开始，读取当前草稿。
- 管理预览与前台复用图片、裁切、说明及查看层呈现规则。
- 查看层置于编辑器缩放容器之外，避免 70vh 再受画布缩放。
- 打开预览时避免编辑器快捷键冲突，关闭后恢复。
- 编辑辅助控件可不同，作品内容的构图、说明和呈现必须一致。

## 七、前台实现

### 查看层结构

推荐原生 dialog 配合独立脚本与共享样式，不新增整套图库依赖。

```text
顶层查看窗口
├── 白色半透明模糊背景
├── 关闭按钮（仅“×”）
└── 查看层布局
    ├── 图片视口
    └── 图片下方说明区域
        ├── 图标按钮（仅有说明时显示）
        └── 摄影说明（点击展开）
```

- 模糊只作用于后方页面，不能模糊整个弹窗。
- 使用顶层查看窗口，避免被页面容器裁切。
- 摄影专属样式隔离，不能改变全站 img、figure、dialog 的通用行为。

### 尺寸与裁切

- 常规图片目标高度 70vh，保持比例。
- 超宽图受可用屏幕宽度限制，必要时高度低于 70vh，完整显示优先。
- 手机可用 dvh 改善地址栏变化，并保留 vh 回退。
- 图片与下方说明控件作为单列内容置于查看层中央；说明不压在图片上。
- 沿用裁切时，以裁切后的可见视口居中；内部图片按裁切参数缩放，不能直接把 transform 放到没有裁切容器的弹窗图片上。

### 说明布局

- 有说明时，图片左下方显示无底色向下箭头，文本默认隐藏；点击后箭头转向右，文本在箭头右侧展开并顶端对齐，再次点击收起。按钮与文本整体宽度按图片说明宽度约束。
- 展开状态不参与图片布局尺寸计算；展开与收起时图片的视口位置及大小保持一致。
- 横向（宽度大于高度）的说明行（按钮和文本）宽度为可见图片宽度的 50%；竖向或正方形说明行宽度为可见图片宽度减 24px，在图片右侧留出约一个箭头宽度。文本填充按钮后的剩余宽度，因此其右边缘与说明行边缘对齐。
- 文本沿用“正文段落”全站样式设置，但字号保持原摄影说明的 12px；左对齐、背景透明且无文本框内边距，支持换行和长单词换行。
- 过长时限制高度，说明内部可滚动，不能遮住关闭入口。
- 点击、滚动、选择说明文字不切换图片；切换图片后沿用当前会话的说明展开/收起状态。
- 空说明不显示图标按钮或占位。

### 交互

| 操作 | 行为 |
| --- | --- |
| 点击图集图片主体 | 从该图打开 |
| 点击原图链接文字 | 正常跳转，不打开查看层 |
| 点击放大图片主体 | 下一张，末尾循环 |
| 点击向下/向右箭头 | 在图片下方展开/收起说明，箭头随状态转向，不切换 |
| 点击已展开说明 | 不切换 |
| 点击背景或关闭按钮 | 关闭 |
| Esc | 关闭 |
| 右/左方向键 | 下一张/上一张，循环 |

单张图片时保持当前项，不闪烁、不重复加载。触发区域避免按钮内嵌链接等无效交互嵌套；可设置独立放大触发区域与链接层。入口需可键盘操作，并有可理解的标签。

### 加载、清理与恢复

- 图片、索引、说明来自同一条目状态。
- 快速切换时旧加载回调不能覆盖新状态，不能出现旧图配新说明。
- 加载中轻量反馈；失败后仍能关闭或切换。
- 按需预加载下一张，不一次下载全图集。
- 路径复用 imageSrc() 及 BASE_URL 规则，兼容 GitHub Pages 子路径。
- 打开时锁定背景滚动，关闭后恢复原滚动状态和页面位置。
- 关闭后焦点回到触发图片，查看期间键盘焦点留在查看层。
- 监听器不能重复绑定；若使用 Astro 页面切换，离开时清理窗口、滚动锁和监听器。

## 八、现有代码冲突与易错点

1. **悬停放大**：摄影图集当前未接入普通图片的悬停效果，后台传入 showHoverZoom=false。新功能保持独立，不复用悬停放大的全局命中/遮挡逻辑。
2. **图片链接**：排除 ImageLinkLabel 的点击，不能一次触发跳转与放大。
3. **后台拖动**：预览按钮和表单阻止必要的拖动事件，但不能在整张图片外层禁用鼠标事件；此前已有设置按钮因 pointer-events 失效的回归。
4. **说明归属**：不能另维护按数组序号对应的说明列表；排序必须移动完整条目。
5. **重复图片**：相同路径不是同一条目，不能以 src 定位或去重。
6. **共享组件污染**：PuckImageEditor 被多模板复用，功能通过显式参数限定摄影图集，不能依赖分类名或 DOM 祖先隐式开启。
7. **保存丢字段**：同时修改类型、双向转换、控件更新、服务端校验和前台读取，否则保存/刷新后可能丢失。
8. **裁切与锚点**：说明定位到裁切视口，不跟随内部图片 transform。
9. **布局变化**：移动端、尺寸变化、懒加载可能改变视觉顺序，必须处理比例占位及重算。
10. **长说明**：防止遮住关闭按钮或图片全部区域；空内容不占位，文字安全转义，不用 innerHTML。
11. **关闭恢复**：避免页面跳动、背景无法滚动、焦点丢失或全局快捷键继续生效。
12. **数据保留**：关闭开关、切换模板不可无声删除说明；替换图片按默认策略保留并记录取舍。

## 十、实施步骤

### 1. 记录基线

- 阅读规则、交接及相关实现，检查已有修改。
- 选一个多图摄影作品，记录桌面和手机布局。
- 核对当前说明、链接、裁切、拖动和撤回。
- 读取当前两端版本，不假定本文记录仍是最新。

### 2. 打通数据

- 增加作品开关及图片说明类型。
- 补齐管理文档双向转换、字符串图片兼容、服务端校验。
- 确保关闭与模板切换保留数据，不批量改写旧内容。

### 3. 管理设置

- 增加摄影模板总开关。
- 传递说明与更新回调，条件显示“摄影说明”表单。
- 接入应用、撤回、重做和反馈。
- 核验排序、删除、替换时说明归属。

### 4. 共享查看层

- 实现居中视口、背景、说明。
- 实现切换循环、关闭、键盘、焦点和滚动恢复。
- 处理快速切换、失败、单张图及后台缩放。

### 5. 视觉顺序

- 测量实际图片视口，建立视觉行并排列。
- 按条目标识定位，打开时计算，布局变化后更新。
- 核验双列不同高度、同顶线、重复文件及手机单列。
- 不得退回数组顺序或 DOM 整列顺序。

### 6. 接入前台和管理预览

- 仅开启功能的摄影图集提供点击入口。
- 排除链接点击，保留原图集布局。
- 管理端提供明确预览入口，复用呈现规则。
