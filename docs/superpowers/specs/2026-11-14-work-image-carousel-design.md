# 作品详情图片轮播设计

## 意图

在作品详情的“添加内容”中增加独立的“图片轮播”区块，让作品作者能把多张图作为一个连续视觉单元展示；访客看到的行为与首页封面轮播一致。

## 目标

- 轮播图片可以添加、删除、排序、上传/选择并分别裁切。
- 前台自动播放并提供左右切换，展示当前序号；手动切换后重新计时，避免定时器与点击竞争。
- 多个轮播区块各自维护状态，互不串扰。
- 画布提供静止预览和手动切换，避免编辑时画面自动移动；沿用现有组件图标和图片操作工具样式。
- 轮播间隔沿用首页的 `rotationSeconds` 设置，避免引入重复设置。

## 非目标

- 不改变现有“图片”“图片组合”、作品主图库或首页封面的数据与行为。
- 不添加缩略图导航、分页圆点、独立播放按钮或每个区块单独的间隔设置。

## 方案比较

1. **新增独立区块（采用）**：增加 `ImageCarouselBlock` / `imageCarousel` 数据类型，独立接入 Puck 画布、数据转换器、详情页渲染与浏览器行为。现有组件保持兼容，行为边界清晰。
2. 扩展“图片组合”：把固定双图组件改成轮播会改变既有语义，并可能让现存内容表现发生变化，因此不采用。

## 交互与视觉

- 添加后显示空轮播占位和“添加图片”入口；有图片时显示一张主图、轻量左右箭头和 `01 / NN` 序号。
- 管理画布只由箭头切换当前预览；每张图复用现有裁切、更换、删除工具，序号与排序列表对应。添加、删除或排序后当前索引保持有效，切到剩余范围内的对应项。
- 访客页面以首页的淡入方式自动切换，间隔使用站点设置；箭头手动切换立即展示目标图并重置单次计时器。少于两张有效图片时不自动播放、不显示切换控件。
- 前台轮播内每张图片保存独立的 `src`、`alt`、裁切位置和缩放；整个轮播共用同一个裁切比例，任一图片确认新比例时同步到轮播内所有图片。不将图片重复写入作品主图库。
- 图标使用统一线性风格：横向轮播框加切换箭头；在添加内容列表与画布组件类别标记中保持一致。

## 数据与实现边界

- `ContentBlock` 增加 `{ kind: 'imageCarousel', images: ContentImage[] }`；Puck 文档增加对应 block 映射和往返转换。
- Puck 编辑器提供视觉化的图像列表管理和单张图像工具；组件预览状态不参与持久化，只持久化图片顺序、图片信息和裁切值。
- Astro 的 `ContentBlock.astro` 输出初始可见图、其他幻灯片及切换控件；独立的客户端脚本为每个轮播容器绑定状态，并清理定时器/事件，避免同页多个轮播冲突。
- 样式继承作品页现有极简灰白视觉和响应式规则；小屏幕继续显示易触控的箭头。

## 验收

- 新区块能保存并重载，图片顺序、裁切值均保留；已有区块数据不受影响。
- 访客页面按首页间隔自动轮播，箭头可循环切换，操作后重新计时且不闪现两张图。
- 多个轮播可以同时存在且互不影响；零张、一张和多张图片状态均合理。
- `npm run build` 成功；本地检查桌面与窄屏下的管理画布及作品详情。
