# 分类列表展示方式

按已讨论方案，为每个分类提供作品缩略图网格、瀑布流、研究日志列表三种展示方式，仅管理页可选择。

- Product 保留方形网格，Visual 和 Photography 初始改为瀑布流，Research Log 保持研究日志列表。
- 方形网格沿用现有封面 imageScale/imagePosition。瀑布流默认原图比例，另存封面比例、缩放、位置；支持原图、3:2、1:1、4:5、2:3。切换展示方式不丢失任何裁切或正文内容。
- 复用现有封面素材；替换素材时重置两套裁切，作品详情图片不变。
- 同宽列、16px 间距，沿用现有列数断点和悬停效果；按作品顺序将下一项放入最短列，等高时从左到右。预留图片高度，避免加载后跳动；窄屏减少列数。
- 前台与管理画布使用一致的排列和裁切规则。保存、撤回、重做覆盖新增字段。
- 兼容原有 grid/research 数据；瀑布流作品仍生成详情路由和站点地图条目。

## 方案比较

统一原图比例最简单，但无法调整封面节奏；限定比例便于排版，但强制裁切。采用已选定的“原图默认、逐件可裁切”，并与方形裁切分开保存。

## 验证

检查三种展示方式切换和保存重读、裁切保存及撤回、桌面与手机排列、图片加载和窗口变化、详情链接及站点地图。按项目规则运行 npm run build，不额外增加测试或发布。
