# 组件快捷复制与跨作品粘贴

## 目标

在作品详情管理画布中通过系统常用复制/粘贴快捷键复制单个已选组件，并可在同一管理页会话中的另一作品画布粘贴。组件正文、设置、嵌套组件和媒体引用随副本保留；粘贴加入现有草稿、撤回和保存流程。

## 范围与约束

- 仅支持单个 Puck 组件，不复制多选范围或作品资料。
- 复制缓存保存在当前管理页会话内，切换作品和分类不清除；刷新或关闭页面后清空。
- 粘贴到选中组件之后；未选中组件时追加到当前模板的主要内容区。图文分栏默认使用右侧内容区。
- 为根组件及所有嵌套 Puck 组件生成新 ID，并同步改写嵌套 zone 键；媒体文件路径继续引用本地现有素材。
- 在可编辑文本字段内保留浏览器原生文本复制/粘贴；未选中组件时 Ctrl/Cmd+C 不拦截系统复制。Ctrl/Cmd+V 仅在画布中有可用组件剪贴内容时拦截。
- 不改变前台作品渲染，也不增加工具栏按钮。

## 方案

1. 当前管理页模块内保存 Puck 组件数据，跨作品重建画布时仍可读取。不会触发剪贴板权限或污染用户的系统文本剪贴板，满足同一管理页中的跨作品操作。**采用此方案。**
2. 写入系统剪贴板 JSON，以支持跨标签页/外部工具；需要浏览器剪贴板权限和格式兼容，且容易覆盖用户原有剪贴内容，本次不采用。
3. 只用 Puck 自带重复动作；只能在源作品内部重复，无法满足跨作品粘贴，本次不采用。

## 交互细节

- macOS 使用 ⌘C / ⌘V，Windows/Linux 使用 Ctrl+C / Ctrl+V。
- 复制只读取当前选中的 Puck 组件及其子 zone，不改动作品。
- 粘贴重建组件 ID 后插入当前 zone；有当前组件选择时插入其后，否则追加到当前模板的主要内容 zone，并选中新副本。
- 粘贴动作进入现有统一编辑历史，撤回可移除副本，重做可恢复副本；保存仍由现有保存按钮完成。

## 验收

- 复制带有嵌套组件的组件后，粘贴副本保留内容和设置，所有 Puck ID 与源组件不同，嵌套 zone 仍完整。
- 从 A 作品复制，切换到 B 作品粘贴，B 作品出现正确副本；撤回、重做、保存和重新载入行为符合现有流程。
- 在正文编辑器、输入框或选中文本时，系统原生文本复制粘贴正常。
- `npm run build` 成功，后台浏览器完成 A 到 B 的实际操作核对；前台不变。
