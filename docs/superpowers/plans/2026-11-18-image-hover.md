# 图片悬停放大实施计划

目标：仅图片组件（含群组内图片）支持可选悬停放大，不包含轮播、免责声明或视频，不加阴影。

设计：图片保存可选 hoverZoom 对象，包含 enabled、scale（1.1–2.5，默认 1.5）、origin（left/center/right，默认 left）。沿用现有工具栏弹窗，编辑时只通过预览按钮触发。前台以独立固定放大层保留当前裁切，避开群组裁切，不改变原有布局；边缘处平移并限制尺寸使图片留在视口内。桌面鼠标生效，触屏关闭；动画 0.3 秒，尊重减少动态效果设置。滚动、窗口变化、Escape 和页面切换关闭放大层。

技术：Astro、React、原生 DOM；不增加依赖。
