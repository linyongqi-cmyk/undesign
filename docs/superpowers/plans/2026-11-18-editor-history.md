# 管理页统一历史记录实施计划

**目标：** 内容每次有效输入和独立画布操作均可撤回、重做；保存和切换页面保留当前管理页会话的历史。
**架构：** 管理页维护共享的记录快照与编辑上下文，Puck 原始文档一并记录，避免空组件及未完成布局在内容转换时丢失。作品使用会话内稳定标识，保存后以磁盘基线重算未保存状态；素材清理保护历史引用。
**技术：** 现有 Astro、React、Puck，无新增依赖。

- [x] 新建独立历史模块：同步记录、重复过滤、分支截断、事务合并、按记录共享快照、素材引用收集。
- [x] 接入管理页草稿、工具栏、快捷键、保存基线；覆盖页面切换、作品移动和改名、创建及回收站。
- [x] Puck 原始文档同步桥接；正文、小标题和参数逐次提交，输入法确认后记录，撤回后保留输入焦点与光标。
- [x] 素材保护接口接入保存及删除流程，避免历史引用失效。
- [x] npm run build；本地浏览器核对逐字撤回、重做、属性修改、跨页、保存后撤回及结构操作。

约束：保留现有极简视觉；不修改作品内容；不推送、不发布。用户要求直接执行。目录无 Git，使用 /tmp 文件备份；遵循 WORKFLOW 不额外添加或运行测试套件。
